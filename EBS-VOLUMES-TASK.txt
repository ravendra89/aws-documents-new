# To verify if EBS volumes are attached to a Linux EC2 instance but not mounted, you can: 
 
Check the console
Open the Amazon EC2 console and navigate to the Instances section. Select the instance, then go to the Storage tab and look at the Block devices section. 
 
Use the lsblk command
Connect to the EC2 instance using SSH and use the lsblk command to list the available block devices. Identify the attached volume. 
 
Use the file -s command
Use the file -s command to get information about a specific device, such as its file system type. If the output shows "data", there is no file system on the device. If the device has a file system, the command will show information about the file system type.
file -s /dev/
